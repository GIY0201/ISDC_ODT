- 직접 이미지 주소: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/september/world.200409.3x5400x2700.jpg
- 가져온 날: 2026-09-23. 지도 영상은 실제 지리를 보여 주는 정적 바탕이며 현재 지구 관측 장면이나 실시간 데이터가 아니다. HTML에 표시한 위성·지상국·링크는 별도 가상 예시다.
- 현재 독립 HTML은 로컬 브라우저의 상대 파일 로딩 문제를 피하기 위해 이 JPEG의 바이트를 `data:image/jpeg;base64`로 직접 포함한다. 이 파일은 원본 출처와 무결성 확인용 로컬 사본이다.
