# 운영자 용어와 설명 시각화 검토

2026-10-07. 현재 웹 화면과 소스의 실제 기능을 기준으로 검토했다. 공식 자료의 업무 구분을 한국어로 옮긴 제품 표시 명칭이며 특정 센터가 승인한 표준 메뉴라는 의미는 아니다.

## 공식 자료

- [ESA 운용 담당 업무](https://www.esa.int/Enabling_Support/Operations/Who_does_what_at_ESA_Mission_Control): 임무계획, 위성 감시와 제어, 비행역학, 데이터 처리와 전달의 업무 구분.
- [ESA 초기 운용](https://www.esa.int/content/view/full/165011): 발사 직후 초기 운용 단계 LEOP.
- [CCSDS 임무계획 및 일정](https://ccsds.org/Pubs/529x0g1.pdf): 임무 활동, 자원과 일정의 관계.
- [ECSS 운용 절차](https://ecss.nl/wp-content/uploads/standards/ecss-e/ECSS-E-ST-70-11C31July2008.pdf): 이상 탐지, 격리, 복구의 구분. 현재 UI는 연구 사례이며 실제 자동 FDIR 기능을 제공한다고 표시하지 않는다.
- [ESA 지상국 표시 안내](https://www.esa.int/Enabling_Support/Operations/ESA_Ground_Stations/ESTRACK_now_-_the_guide): 지상국과 위성의 교신 관계, 가시성과 실제 자료 수신 구분.

## 적용한 메뉴 체계

| 기존 표시 | 변경 표시 | 화면 목적 |
|---|---|---|
| 공용 상황판 | 통합 관제 현황 | 위성군 위치와 운용 상태 확인 |
| 정상 임무 흐름 | 정상 운용 절차 | 임무 접수부터 결과 전달까지의 인계 |
| 초기 운용 흐름 | 발사 초기 운용 | 분리부터 첫 교신까지의 절차 |
| 장애 복구 흐름 | 이상 대응 및 복구 | 탐지, 대응 판단과 복구 확인 |
| 임무 결과 | 임무계획 및 결과 | 요청, 작업 계획과 결과 확인 |
| 지상 운용 | 운용 판단 및 인계 | 영향 판단, 승인과 교대 인계 |
| 모듈 연결 설정과 ICD | 시스템 연동 설정 | 연결과 인터페이스 명세 구성 |
| 장면 구성 | 시험 환경 구성 | 위성, 지상국과 시작 조건 입력 |
| 시나리오 작성 | 시험 시나리오 작성 | 시험 절차와 장애 조건 작성 |
| 실행 기록 설계 | 모의실험 실행 및 기록 | 재생 제어와 기록 확인 |
| 비교 검증 | 시험 결과 평가 | 결과 비교와 평가 |

SIM은 모의실험, ICD는 인터페이스 명세, EM은 시험용 장비, ACK는 명령 수신 확인으로 표시한다. 모의 장비 시험을 실장비 시험으로 바꾸지 않는다. 원본 JSON, 코드, 입력값, 명령 ID, 제공자 출처는 그대로 유지한다. 동적으로 갱신하는 문구에도 적용하며 재적용은 멱등이어야 한다.

## 시각화 후보 조사

다음은 구현 후보이며 신규 그래프를 모두 적용했다는 기록이 아니다.

| 화면 | 적합한 시각화 | 대체할 설명 | 현재 자료와 조건 | 우선순위 |
|---|---|---|---|---|
| 정상 운용 절차 | 담당자별 업무 인계 단계도 | 누가 어떤 근거로 다음 업무에 넘기는지 | 현재 절차 카드 재배치 가능. 운용 예시 표시 유지 | 높음 |
| 발사 초기 운용 | 분리, 초기 궤도 확인, 첫 교신 시간축 | 초기 운용 단계와 다음 확인 항목 | 입력 시각과 계산 시각 구분. 미산출 첫 교신을 가짜 시간으로 표시하지 않음 | 높음 |
| 이상 대응 및 복구 | 탐지, 원인 확인, 대응 검토, 조치, 복구 확인 단계도 | 길게 나열된 대응 질문과 증거 | 현재 독립 연구 사례 재사용. 미확인 단계는 완료 색상 금지 | 높음 |
| 지상국 및 통신 | 지상국별 교신 가능 시간표 | 여러 가시 구간의 시각 나열 | 기존 조회 구간으로 UTC 축 표시. 가시성을 실제 통신 성공으로 표현하지 않음 | 높음 |
| 시스템 연동 설정 | 위성, 지상국, 관제 시스템 연결 구성도 | endpoint와 연결 목록 | 기존 연결도 보완. 실제 연결 상태와 구성 초안 구분 | 높음 |
| 모의실험 실행 및 기록 | 전력, 저장량, 지연 추이 그래프와 이벤트 표시 | 지표 숫자와 사건 목록 | 현재 값 하나만 있을 때 선 그래프 금지. 수신한 시계열 표본에 한정 | 중간 |
| 시험 결과 평가 | 단계별 비교 표와 단위별 그래프 | 정상, 장애, 우회, 복구 결과 비교 | 기존 비교 표 유지. 지연, 신뢰도, 용량은 서로 다른 축 사용. 결측값은 0으로 만들지 않음 | 높음 |
| 임무계획 및 결과 | 작업 일정표 | 작업 시작, 기간, 선행 작업의 나열 | 기존 서버 작업 시간과 선행 관계 사용. 시각 단위와 모의실험 기준 명시 | 중간 |
| 임무 데이터 관리 | 생성, 저장, 전송, 수신 경로도 | 데이터 계보와 전달 상태 설명 | 실제 기록이 없는 구간은 미연동 표시. 예시 경로를 실제 전달로 표현하지 않음 | 중간 |
| 장비 연동 시험 | 연결 상태 및 시각 동기화 표 | 영문 상태와 오프셋 문구 나열 | 기존 모의 사전 점검 자료 사용. 실제 장비 검증 증거와 분리 | 중간 |

항상 값, 단위, 시간 기준과 자료 출처를 함께 표시한다. 색상만으로 성공과 실패를 구분하지 않는다. 표 또는 설명 버튼으로 같은 정보를 확인할 수 있어야 한다. 화면에 이미 있는 지도, 비교 표와 그래프를 먼저 개선하고 중복 시각화를 추가하지 않는다.
