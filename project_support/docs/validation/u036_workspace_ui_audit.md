# U036 전체 작업 화면 UI/UX 검토 및 수정

2026-10-08, 제품 주소 `http://103.218.163.201:8891`. `ui-ux-pro-max`의 정보 계층, 점진적 정보 공개, 읽기 순서, 키보드 초점 지침을 현재 화면에 적용했다. 기존 사용자 탭은 유지하고 별도 검증 탭에서 점검했다.

## 점검 방법과 범위

왼쪽 8개 메뉴 그룹과 환경 설정을 열어 기능 탭, 설명 버튼, 접힌 상세를 확인했다. 스크롤 영역은 화면 높이의 약 70%씩 겹치게 이동하여 하단까지 확인했다. 처음에 스크롤이 막혀 있던 화면은 결함으로 기록하고, 수정 후 같은 하단 내용을 다시 확인했다. DOM 텍스트만 읽고 스크롤 검증을 대체하지 않았다.

|---|---|
| 상황판 | 통합 관제 현황, DT 통합 상황판, 모듈별 상태, 연결 목록 |
| 위성 | 위성 찾기, 실시간 및 시각별 분석, 위성군 구성, 저장 궤도 분석, 저장 궤도 거리·도플러, 발사 초기 운용 |
| 지상국 | 지도와 지상국 설정, 공개 목록과 저장 관리, 배치 위성 통신 분석의 모든 상세, 선택 위성 가시 시간, 저장 궤도 구간 분석, 시나리오 통신 계획, RF 링크 계산, 저장 궤도 가시 구간 |

| 데이터·보안 | SDC 데이터 관리와 원본 보고/정책 상세, 보안 상태와 실행/시각/연결 상세 |

위성 목록은 표시된 첫 페이지 100행을 내부 스크롤 끝까지 19번의 겹치는 이동으로 확인했다. 전체 16,689개 데이터 레코드를 모두 검토했다는 의미는 아니다. 시스템 연동의 18개 모듈, 17개 연결, 8개 인터페이스 상세는 모두 펼쳐 확인했다.

검증 탭에서 보이는 현재 데이터와 빈 결과 상태를 점검했다. 새 위성 배치, 시험 실행, 장애 주입, 장비 명령, 저장 설정 변경으로 별도의 결과를 만들지는 않았다. 계산·저장·시간 소유권의 상태별 동작은 회귀시험 근거와 구분한다.

## 중복과 기능 구분에 대한 결정

| 발견 | 반영 |
|---|---|
| 위성·지상국·데이터·보안·장비 화면에 실제 기능과 비슷한 이름의 고정 예시 탭이 함께 노출됨 | 5개 경로에서 중복 예시 탭을 제거하고 실제 기능 화면을 유지 |
| 위성 작업의 첫 화면이 저장 입력 중심이며 카탈로그/시간 분석 목적이 이름에서 드러나지 않음 | `위성 찾기 → 실시간 및 시각별 분석 → 위성군 구성 → 저장 궤도 분석 → 저장 궤도 거리·도플러`로 정리 |
| 지상국 지도와 저장/계산 도구가 길게 이어져 기본 작업이 묻힘 | 지도와 선택 지상국을 앞에 두고 `지상국 목록 및 저장 관리`, `배치 위성 통신 분석`을 기본 접힘으로 묶음 |
| 같은 가시 시간처럼 보이지만 선택 카탈로그 위성, 저장 궤도, 배치 위성, 시나리오가 다른 입력을 사용함 | 입력 대상에 맞춰 이름과 기준 시각을 명시. 계산 기능을 임의 삭제하거나 입력을 합치지 않음 |
| `앞으로 24시간`이 과거 분석 UTC에도 표시됨 | `선택 시각부터 24시간 조회`로 수정하고 위성·기준 시각·등록 지상국 조건을 함께 표시 |
| 군집 서비스 임무와 SIM 임무가 겉보기에는 유사함 | 실제 UTC 기반 군집 계획과 0~100 축의 SIM 편집기가 서로 다른 기능이므로 유지 |

정상 운용, 인계, 초기 운용, 시설 점검 화면은 고정 예시를 사용한 절차 참고 기능으로 남긴다. 실측 상태판이나 실제 조치 실행 기능이 완성되었다는 의미가 아니다.

## 가시성·가독성 수정

- DT 상황판을 작업 창의 스크롤 영역에 포함했다. 모듈·연결 상세와 하단 결과 버튼까지 접근할 수 있다.
- 정적 절차 화면의 내부 카드가 강제로 축소되면서 하단 내용이 잘리던 문제를 수정했다.
- 시험 환경의 소개문이 공간을 차지해 위성군 편집 영역이 17px까지 줄어들던 문제를 없애고 하나의 바깥 스크롤로 읽게 했다.
- 지도와 작성 폼은 브라우저 전체가 아니라 실제 작업 창 너비에 맞춰 재배치한다. 지도는 620px 이하에서 쌓고, 작성 폼은 760px 이하에서 쌓는다.
- 데이터 원본 보고와 정책 JSON, 태양 계산 근거는 필요한 경우 펼쳐 읽는다. 데이터 기본 본문은 같은 검증 조건에서 2740px에서 1954px로 줄었다.
- 실시간 상태 갱신이나 화면 재생성 이후에도 사용자가 펼친 상세를 유지한다. 직접 닫은 상세는 계속 닫혀 있다.
- 숨긴 고급 설정의 설명이 일반 `i` 도움말로 다시 노출되지 않게 했다.
- 표 제목의 색을 현재 테마에 맞추고 긴 값 줄바꿈, 정의 목록 정렬, 키보드 초점을 보완했다. 시계가 작업 창 하단 버튼을 가리지 않도록 했다.
- 카탈로그 위치 안내 `i`는 표시 해제 버튼 오른쪽에 둔다. `GP epoch 초안` 등의 버튼 문구를 `궤도 자료 시각 사용`처럼 바꿨다.
- 마지막 시각 검증에서 좁은 화면의 헤더 숨김 스타일이 `i` 팝업 안의 설명까지 숨기는 결함을 발견했다. 팝업 내부 설명에만 표시 규칙을 적용했고, 빈 34×34px 상자가 실제 설명을 담은 418×94px 내용 영역으로 바뀐 것을 확인했다.

## 실제 수정 후 재확인 근거

- DT 상세: 본문 597px, 전체 1857px, 스크롤 1260px 끝. 이후 실시간 갱신에도 펼침과 스크롤 유지.
- 정상 운용: 597/759px, 끝 162px. 운용 판단 및 인계: 597/770px, 끝 173px.
- 지상 시스템 관리: 최종 1057×884 브라우저, 작은 창 본문 473/901px에서 0→331→428px 끝. 이전에 가려진 복구·증거·인계 카드까지 확인.
- 시험 환경: 487/2269px, 끝 1782px. 상세 확장 후 487/2665px, 끝 2178px. 내부 JSON도 384/1497px, 끝 1112px.
- 지상국 구성: 최종 두 열 작은 창 본문 389/1166px에서 0→272→545→777px 끝. 관리·분석의 모든 상세도 이전 재검증에서 펼쳐 하단까지 확인.
- 위성군: 본문 395/1807px, 끝 1412px. 원본 정의 확장 후 395/2203px, 끝 1808px.
- 위성 찾기: 표 내부 350/4685px, 끝 4334px. 표 바깥 본문과 위치 설명도 별도로 확인.
- 환경 설정: 현재 KST와 실제 음영 표시 상태가 기본 화면에 나오며 EOP/UT1 등은 `태양 계산 정보`에서 확인. `전체 위성 표시`는 같은 기본 설정에 ON/OFF로 표시.

## 자동 검증과 적용

회귀시험 실패를 먼저 재현한 뒤 구현했다. 탐색 구조, 상세 펼침 유지, 숨긴 도움말 제외, 레이아웃, 지상국 상세, 등록 지상국 조건, 태양 정보 분리에 대한 RED 로그와 수정 후 로그를 `project_support/u036_*.log`에 보존했다.

Python 전체: `967 passed, 8 skipped, 8 warnings` (315.71s, `project_support/u036_python.log`). 경계 연도의 ERFA 경고가 포함되어 있다.

최종 JavaScript 전체: `2195 passed, 0 failed, 1 skipped` (31.83s, `node --test project_support/tests/browser/*.test.mjs`, `project_support/u036_node_complete.log`). 마지막 도움말 표시 수정까지 포함한 결과다. 변경 범위 `git diff --check`도 통과했다. 검증 탭의 마지막 콘솔 오류 조회는 0건이었다.

초기 전체 JavaScript 실행의 2개 실패는 이번에 바꾼 설명 문구와 전체 위성 스위치의 새 부모 요소에 대한 기존 기대값이었다. 원인 확인 후 기대값을 실제 소유 구조에 맞추고 전체 시험을 다시 실행했다. 초기 실패 기록은 `project_support/u036_node.log`에 남겨 두었다.

정적 프런트엔드 수정으로 서버 재시작은 필요 없다. 기존 사용자 탭은 새로고침해야 변경 코드를 읽는다. 실행 중인 SIM, DB 정의, 궤도 계산식, API 계약은 변경하지 않았다.
