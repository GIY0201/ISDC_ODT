# ADR0021 Mutable workspace asset revalidation
2026-10-06. Actual owned8891 replacement exposed cached old catalog module mixed with current workspace assembly, raising observeSelection missing. Revalidate GET/HEAD HTML and /static JS/CSS/JSON using Cache-Control:no-cache, preserving browser storage and ETag304 conditional reuse. Binary GLB/images and APIs retain their current caching policy. No-cache requires validation and does not disable storing responses. This avoids query-version changes on every transitive import; immutable fingerprinted assets can be considered when a build pipeline exists. Regression covers200/304 and unchanged API/binary headers; ordinary actual browser reload passed. See validation/t151_live_runtime.md. This does not establish coherent atomic updates across arbitrary deployments or all tabs.
