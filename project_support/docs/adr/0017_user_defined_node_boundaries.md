# ADR0017: source-defined satellite nodes and accepted data deployment

Status: design accepted for staged implementation under the existing T075–T084 goal; implementation and live acceptance pending. Date2026-10-05. Full contract: project_support/specs/001-v6-function-integration/contracts/satellite_nodes.md.

Problem: source user-placed nodes use Kepler+J2 with an explicitly pseudo-inertial/GMST-only frame, not GP SGP4/TEME/precise ITRF. Source local deployment copies are updated only after a separate accepted data-management server transaction. Reusing only a local store or treating source coordinates as precise would omit behavior or misrepresent the model. Source initialize auto-POST on restore conflicts with the product's no-command-on-restore rule.

Decision: add source-equivalent node math to the existing Rust crate with an additive native export and new wheel version/receipt; preserve all old exports/profile/goldens. Static browser orbital-definition validation/summary is injected into a pure node library, time-dependent propagation stays native. Explicit epoch/IDs/storage/executor/Viewer/UTC injection replaces global singleton/default wall clock. Public node frame/time/profile distinguish engineering GMST/Unix-ms approximations; source-unrepresentable leap rows return errors. Don't transform a pseudo-frame as if it were TEME. Exact buffer schema/serialization is pinned by native adapter tests before release, with immutable owned bytes and aligned errors.

Decision: preserve original deployment GET/POST wire schema and runtime atomic activate-then-commit/expected revision/idempotency/run-scope semantics. T079 must provide a verified isolated-v1 data-management activation port; unavailable is503, never a successful stub. A readonly initialize/restore replaces original automatic restore POST. Explicit deployment captures the sent roster, serializes and validates receipts before local copy update; conflict reapply is explicit. This is an intentional behavior change, not part of a structural move. Deep-copy/nonfinite/duplicate/storage-failure validation repairs are likewise documented and tested separately.

Consequences: original equations/presets/formation/power values remain directly comparable with captured source results. Models are approximate and do not imply measured orbit, precise EOP, battery SOC, actual RF/OISL or HIL. Source120 track intervals mean121 vertices with rounded-period/Date TimeClip/hide-all-on-missing semantics. max240 nodes is retained via bounded native chunks; no subset-only completion. A source-model or performance upgrade needs separate evidence and must not silently replace these contracts. Native installation/server restart requires state preservation and fixed8891. Product/API/native/UI acceptance and Draft publication remain unfinished; existing T075–84/T032/Terra/equipment/download/AeroDT requirements stay open.
