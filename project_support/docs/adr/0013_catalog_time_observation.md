# ADR0013 카탈로그 시간 탐색과 관측 표본

기존 카탈로그의 GP 선택·정규화와 Rust SGP4, 공식 EOP 기반 ITRF 변환을 재사용한다. 저장 GP/UTC와 SIM의 권위 상태를 변경하지 않는 `POST /api/catalog/samples`를 추가한다. 기존 position API는 epoch 기준 위치 조회로 유지한다.

선택 당시의 normalized GP SHA-256을 요청에 포함하고 현재 자료와 다르면 native 계산 전에 409로 거절한다. 요청은 명시 UTC, 최대 601개, 정수 SI 간격 1–60초, WGS84 가상 관측 지점과 최소각을 사용한다. 서버 계산은 기존 제한 executor에서 실행한다. 실패한 native 표본은 수치와 visibility를 null로 반환하며 정상 위치를 발명하지 않는다. EOP 범위 밖 422, 미제공·busy 503을 유지한다.

관측 거리는 기존 WGS84 지점과 ITRF 위성 위치 차이의 norm, 방위각은 ENU 북쪽 기준 시계 방향이다. 천정의 방위각은 null이다. 고도각은 기존 계산을 그대로 사용한다. 지형·굴절·RF·장비 조건을 포함하지 않으며 최소각 충족은 실제 통신 가능 판정이 아니다. 원본 지상국 높이는 기준면 미확인으로 자동 복사하지 않는다.

브라우저 시간은 별도 표시 상태다. 기존 윤초 codec과 1초 sample buffer를 재사용하고 601초 표본 창을 300초 겹쳐 갱신한다. 배속 0.1/1/10/60, 명시 UTC와 epoch 복귀를 지원한다. 위치·고도각은 1초 표본 사이에서만 보간한다. 거리·방위각은 앞 native 표본 시각을 함께 표시하여 보간 위치 시각과 구분한다. 틈·오류·자료 밖에서는 위치를 숨긴다. 세대/AbortSignal/context/hash 검증으로 늦은 응답을 폐기한다. 단일 Viewer와 기존 저장 GP 계산 흐름을 유지한다.

검증: feature validation/t103_catalog_time.md. T075의 다중 위성·3D·태양과 다른 T076–T084를 이 ADR의 완료로 간주하지 않는다.
