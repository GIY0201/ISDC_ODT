# ADR0063: 관제센터 화면별 지구 표시 자원

상태: 독립 읽기 전용 설계 검토 통과, 회귀시험부터 구현 중. 실제 화면 검증은 대기.

사용자는 메인과 공용 상황판을 두 대형 화면에 동시에 표시하고 역할별 운용자가 같은 서버 상태를 조작하는 환경을 요구했다. 하나의 지구 DOM을 상황판으로 이동하는 구현은 메인 배경을 없애므로 폐기할 설계이며 코드와 자료는 보존한다.

계산과 현재 상태의 소유권은 기존 runtime 및 source controller에 남긴다. 화면마다 Cesium 표시 자원과 카메라를 두며 같은 문서의 두 화면은 검증된 불변 투영을 공유한다. 원본 node renderer binding을 두 번째 화면으로 교체하지 않는다. replica는 원본 scene과 timeline의 등록된 읽기/검증 포트를 사용하고 종료 시 자체 자원만 해제한다. 원본 시계의 실제 UTC를 따라가며 별도 시계를 만들지 않는다.

다른 문서의 운용 화면은 기존 서버 API의 run, revision, scope 검증을 따른다. BroadcastChannel의 UI 초안은 권한 자료가 아니다. 별도 문서 동기화는 두 클라이언트의 실제 명령과 결과 반영 증거가 필요하다. 구현 전 독립 설계 검토 및 회귀시험을 수행한다.
