# Quickstart validation

개발 루트에서 project_support/.venv/Scripts/python.exe -m pytest -q를 실행한다.
Node 실행: node --test project_support/tests/browser/*.test.mjs.
서버: project_support/.venv/Scripts/python.exe main.py --host 127.0.0.1 --port 8776 --no-browser.
공용 지구와 역할 목록을 확인한다. 위성 검색/필터, 지상국 RF 계산, 임무 편집/재계획, 분석 내려받기와 MOCK-HIL preflight를 실행한다.
창 이동/버튼 이동, 크기/버튼 크기, 최소화/복원, 확장, 닫기, 팝업 및 뒤로/앞으로를 확인한다.
1280x720과 1920x1080에서 제어 접근과 작업 내용 스크롤을 확인한다.
GP/SIM/MOCK-HIL/미연동 표시를 확인한다. 실제 장비 또는 영구 recording/replay로 해석하지 않는다.
