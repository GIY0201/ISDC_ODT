# T143 native adapter partial implementation

Added immutable `PreparedNodeDefinition`/`NativeNodeBatch`/`NodeGeometryPort` contracts and `communication/native/node_adapter.py`. Preparation copies source-node values into immutable JSON, hashes the complete supplied record, checks schema/virtual identities/duplicates/finite orbit inputs and retains explicit unsupported leap epochs. Native requests are bounded to240definitions/601samples each/50000rows. This adapter currently handles a shared sample-time grid; per-node track grids and the application/HTTP layer remain pending.

The adapter does not propagate or transform orbits in Python. The injected native export supplies31-column little-endian owned rows. Exact profile/frame/time/width/limit metadata is required; missing or incompatible native capabilities raise OrbitUnavailable. Buffer length/error alignment/type/finite successful rows/sunlit/height/geographic bounds/Sun and LVLH unit norms are checked before success is exposed. Failure rows return None; fixed km→m conversion is applied exactly once. Inertial velocity remains native km/s and is not relabeled Earth-fixed. Public rows/IDs/hashes/UTC/errors are immutable values with independent owned bytes.

Unix-ms conversion uses Gregorian days plus ordinary clock seconds/fraction. Astropy UTC quasi-JD/unix day stretching is not used for this source convention. Tests verify1970/negative Unix time/last ordinary second on2016-12-31/next midnight/fractional millisecond. Valid :60 sample rows and leap epochs become unsupported_node_time without entering native, while neighboring ordinary rows keep their original order and Unix timestamps. Malformed calendars/time zones are rejected rather than normalized into valid input.
