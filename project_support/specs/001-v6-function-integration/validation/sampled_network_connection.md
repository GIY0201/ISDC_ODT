# 지상 통신망의 분석 시각 표시 연결

원본 ISDC-ODT `1a1e00297a0301637455b0ef2cf48b2e74576b07`의 통신망 계산을
기존 네트워크 소유자에서 재사용한다. 광통신 분석 뒤 같은 분석 UTC의 전체
native 입력을 사용하며 광통신 이력을 다시 진행하지 않는다. 기존 1초
스케줄러 하나가 두 계산을 순서대로 실행한다.

등록된 `NETWORK_SAMPLED_UI_V1`은 표시 전용이다. 분석 UTC, 표시 UTC, 경과
시간과 갱신 중 상태를 분리한다. 품질, 보관 상태, 경로, 패킷 흐름과 정확
UTC 명령 승인을 이전 표시 결과로 만들지 않는다. 지상 화면 진입은 명시적
활성화이며 화면 이탈과 초기화는 먼저 표시 권한을 해제한다.

변경 전에 없는 조립 포트와 첫 재생 프레임의 결과 손실을 실패 시험으로
확인했다. 실제 카탈로그 소유자와 전체 240개 노드의 조립 시험은 1280×720,
1920×1080에서 2개 통과했다(13334.9982 ms). 실제 HTTP, 물리 계산과 GPU는
이 시험의 통제된 어댑터이며 실제 운용 성능의 증거로 쓰지 않는다.

별도 검토에서 화면 콜백 예외, 같은 UTC 권한 철회, 중첩 갱신, 마지막
검증에서 Viewer 교체 문제를 재현하고 수정했다. 화면과 연결도 21개,
renderer 25개, 분석 소유자 관련 72개 시험 통과. 최종 등록 소유자의 검증
함수는 renderer를 수정하지 않는 관찰 계약을 유지한다.

연결도의 기본 출력은 변경 전 Git 36821fb에서 추출한 10개 출력의 SHA256과
대조한다. 원본 LF/CRLF 소스 해시를 함께 보존했다. 새 선택 사항
`unverifiedAnalysis`만 표시 품질을 미확인으로 제한한다.

전체 Node 시험 1426개 통과, 실패와 skip 없음(23280.4358 ms).
증거: `data/workspace/validation/full_migration_node_N016.log`.
전체 Python 시험은 965개 통과, Pillow 관련 기존 skip 1개와 ERFA 경고 8개(230.58 s), 프로세스 exit 0을 확인했다. 증거: data/workspace/validation/full_migration_python_N016.log.

Context7 공식 Cesium 문서 확인은 `sampled_optical_connection.md`에 기록돼
있다. 설치된 1.143의 이벤트와 primitive 수명 규칙을 대조했으며 자동 버전
업그레이드는 하지 않았다. N016 실제 화면 및 GPU, N017 읽기 전용 통신
수명주기, N018 정확 권한의 주기적 교환과 전체 T075–T084는 아직 열려 있다.
