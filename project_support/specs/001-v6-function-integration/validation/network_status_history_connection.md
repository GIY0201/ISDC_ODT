# 통신 모듈 조회와 과거 링크 품질 연결

N017의 일부 연결 기록이다. 원본 통과 구간 갱신, 3D 지상국 선택 및 초점,
OISL 경로 강조와 N018의 주기적 교환은 별도 미완료 항목이다.

## 원본과 구현 경계

원본 기준 커밋 1a1e00297a0301637455b0ef2cf48b2e74576b07의 통신 화면은
활성 화면에서 30초마다 모듈 상태를 조회하고 링크 품질을 48개까지 보관한다.
기존 fabric 소유자와 DataFabricClient를 재사용했다. 자동 조회는 GET만
수행하며 명시적인 미확인 요청 검토, 전송, 경로 요청을 실행하지 않는다.
조회 결과와 통신망의 현재 수락 결과를 별도로 표시한다.

품질은 실제 수락된 모듈 응답에서만 기록한다. 알려진 사용 불가 링크의
원본 0과 미확인 값을 구분한다. 같은 링크의 이전 UTC와 입력 hash는 과거
근거로 보존하고 endpoint 및 모듈 실행이 바뀌면 정리한다. 제거된 링크의
이력도 정리한다. 원본 drawSparkline에 이 사본을 전달한다.

## 회귀시험과 검토

구현 전에 없는 API와 UI 연결을 실패 시험으로 확인했다. 독립 검토에서
명령 시작 중 조회의 재진입, 종료 후 조회의 복구, 마지막 endpoint 확인
중 native UTC 변경을 재현하고 수정했다. 추가 검토에서 취소 이벤트가
새 조회를 시작하는 경우를 발견해 조회 시작 전 취소, 취소 중 재진입,
invalidate 및 종료 경계를 실패 시험으로 확인하고 수정했다.

UI의 마지막 콜백에서 이력이 정리되면 이전 차트를 노출하지 않도록
회귀시험으로 확인했다. 실제 workspace 조립과 DataFabricClient를 사용한
두 해상도 시험에서는 활성 화면의 GET-only 조회와 종료 시 정리를 확인했다.
HTTP, DOM, Cesium 경계는 시험 어댑터이므로 실제 GPU나 운용 증거가 아니다.

Context7 CLI의 /mdn/content 공식 AbortSignal, fetch 및 abort-event 문서를
조회해 취소 동작을 대조했다. 문서 확인은 앱 상태 소유권이나 실제 화면
검증의 대체 근거로 사용하지 않는다. 상세 출처는 research_network_lifecycle.md.

최종 독립 소유자 검토 35개 통과, UI를 포함한 관련 집중 시험 58개 통과.
전체 JavaScript 회귀시험은 1,465개 통과, 실패와 건너뜀 0개,
25,136.1955ms, 프로세스 종료 코드 0이다. 로그:
data/workspace/validation/full_migration_node_N017_status.log.
전체 Python 회귀시험은 965개 통과, 기존 Pillow 의존 시험 1개 건너뜀,
기존 ERFA 경고 8개, 237.35초이다. 로그:
data/workspace/validation/full_migration_python_N017_status.log.
실제 8891 화면의 최신 연결 결과는 확인 후 추가한다.
