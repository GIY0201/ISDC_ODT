## Native engineering-model calculation

- Port source orbital-domain/Kepler Newton iteration/J2 secular rates/rotation/GMST/WGS84 conversion/low-precision Sun/cylindrical shadow/LVLH equations into node_dynamics.rs inside the existing orbit_propagation crate. No new browser propagator or SGP4 fallback. Existing TLE/OMM exports/profile/limits/calculation results stay unchanged; additive node export and versioned wheel require ADR0017 and native installation receipts.
- Distances km, speed km/s, interface times Unix milliseconds, angles degrees; source model elapsed time is the difference of those Unix-ms values, not an SI/UT1/TT accuracy claim. Explicit canonical UTCs are supplied by the existing display owner through foundation/orbit_time, with no new wall/playback clock. Requests use an SI-spaced UTC grid, but source arithmetic remains tagged unix_ms_utc_approx. Leap-second rows or leap-second epoch cannot be represented faithfully by the original Unix-ms/Date convention: return explicit unsupported_node_time and hide those rows, never collapse :60 into a normal second or substitute Date.now.
- Native states carry original pseudo-inertial r/v, GMST-only fixed r, low-precision source Sun, LVLH, radius/angles and WGS84 geodetic outputs. Include negative/large/fractional offsets, e/domain edges, rotation/LVLH/energy consistency and every retained source golden.
- Native output is owned contiguous little-endian float64 with aligned per-row errors; no nonfinite numeric row reaches JSON/renderer. Retain max50000rows per batch, max240 distinct nodes, max601 samples per node.
