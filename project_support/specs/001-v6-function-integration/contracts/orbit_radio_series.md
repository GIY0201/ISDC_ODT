# Radio series v1
POST /api/orbit/radio-series: requestID 1..128 nonblank, inputID1..100 nonblank, selection_revision integer>=0, frequency_hz 0<f<=3e11 finite nonbool, start_utc/end_utc UTC Z canonical9digits. extra/bool/NaN reject. 0<SI duration<=86400, count=min(601,ceil(duration)+1). 양끝 포함, uniform SI step, 마지막 UTC 정확 end. 서버는 가시 구간 여부를 새로 판정하지 않는다.
응답은 단일 radio metadata/units/assumptions/model/communicationunknown/stale 및 start/end/duration_seconds/step_seconds,rows(단일radio calculation 행+valid/error),status complete|partial|error. 행 순서/개수/정확UTC/주파수/hash/frame/profile/수치관계 검증. 오류행 위치/속도/모든metric null. selection conflict409/missingcalculator+busy503/EOP범위422.
UI는 ready 가시결과에서 interval index를 선택, 접점0초 제외, 원본 clipped 표시. 선택항목의hash/revision/ground/minElev/UTC/EOP/leap/frame/profile검사, remote interval 선택은 지원하지 않고 주파수같은값도invalidates. 최근접/최대abs 도플러는 표본중이며 continuous extrema아님. 일부오류면 전체 요약 없음, 그래프 gap 및 오류목록. 단일시점/RF/GP/UTC불변. 입력과결과 화면사본은복원되지만 selection변경/새조회/취소로폐기. 실제수신미확인.
