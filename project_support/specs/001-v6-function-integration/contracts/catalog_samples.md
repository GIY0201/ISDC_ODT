## Additive native detail extension (version 1)

The installed Rust0.3.0 TEME six-column result supplies speed; the existing precise ITRF transform supplies ERFA gc2gd(1) WGS84 geodetic coordinates. No new propagation, native ABI or mutable state is introduced. Metadata: details_version=1, details_profile=WGS84_ERFA_GC2GD_TEME_SPEED, details_units={latitude:deg,longitude:deg,ellipsoid_height:m,teme_speed:km/s}. Values: geodetic={latitude_deg,longitude_deg,ellipsoid_height_m,ellipsoid:WGS84}, teme_speed_km_s. A declared extension requires complete exact metadata and finite valid values; absent extension remains compatible with legacy injected calculators. Values describe the native sample UTC, not measured telemetry.
For samples, metadata is top-level and values are per-row; failed rows have both values null. Browser interpolation never interpolates or relabels these details: details_utc retains the original native row UTC.
