Reuse bootstrap, runtimeControl(start,pause,reset,step), runtimeSpeed(0.1–128), selectScenario(server IDs), injectFault and telemetrySocket. No backend, physics or schema changes.
Runtime is authoritative; browser copies status, metrics, events and missions. One lazy socket per page survives navigation; pagehide closes it. Existing reconnect is retained. A 3.5s inactivity watchdog marks last-known data stale. Pending commands ignore stream frames; bootstrap confirms command outcome; compatible run/scenario/running/speed/sequence plus fault ID guard prevents older frames overwriting the response. Explicit refresh recovers uncertain outcomes. Existing wire has no command revision/CAS; concurrent operators can change state afterward.
SIM elapsed seconds differ from orbit UTC. Step adds max(speed,1) seconds and pauses. Reset clears elapsed/faults, changes run ID and pauses; missions/events/speed/scenario remain. Scenario load clears elapsed/faults, changes run ID, preserves running/speed/missions. Paused faults expire on SIM time, not wall time. Fault target/severity are recorded metadata; legacy calculation applies kind globally. Paused injection can leave previous metric snapshot until step/resume; label snapshot separately.
All metrics are deterministic SIM. No real authentication/health/RF/HIL/recording guarantee. Unknown units remain raw keys. Scenario names including HIL do not turn this into actual HIL. Forms preserve native nodes on streaming and draft changes; remote drafts never submit commands. Mission readonly updates preserve edits; server changes invalidate validation/preview.
