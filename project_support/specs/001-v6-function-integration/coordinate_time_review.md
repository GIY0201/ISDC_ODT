# 좌표, 시간 및 지상국 고도각 검토안

상태: speckit-plan Phase 0 연구 결과. 제품 구현과 실제 수치 시험은 아직 하지 않았다. R005 정확도, R007 검증, R008 계산 경계에 연결한다.

## 계산 경로
Rust SGP4의 TEME 위치를 UTC 시각과 함께 받는다. UTC와 UT1의 차이 및 극운동 xp/yp를 보존한 지구 회전 보정 자료(EOP)를 사용해 지구 고정 좌표 ITRF로 변환한다. TEME를 J2000으로 취급하지 않는다. UT1 기반 IAU1982 GMST 회전과 극운동의 정의 및 부호는 Vallado 기준으로 고정한다.

지상 관측점은 WGS84 측지 위도, 경도, 타원체 높이로 정의한다. 위성과 지점의 지구 고정 위치 차이를 동쪽, 북쪽, 위쪽(ENU) 성분으로 바꾸고 elevation = atan2(up, hypot(east, north))로 기하학적 고도각을 계산한다. 대기 굴절, 지형 차폐 및 안테나 조건은 이 계산에 포함하지 않는다. 고도각 10도 이상이라는 결과를 통신 성공으로 표시하지 않는다.

SGP4 전파의 WGS72 상수와 관측점 좌표의 WGS84 타원체는 서로 다른 책임이다. 한쪽을 다른 쪽에 맞추기 위해 임의 교체하지 않는다. 속도 변환은 지구 회전 항 및 LOD 조건까지 고정해야 하며 위치 회전 행렬만 적용하지 않는다.

## 재현성 계약 제안
EOP 원문, 제공 기관, 조회 시각, 적용 날짜 범위, SHA256, 확정/예측 상태, 보간 방법 및 윤초 자료 버전을 기록한다. 실행 중 자동 다운로드로 결과를 변경하지 않는다. 자료가 적용 범위를 벗어나거나 없으면 정확도 검증 불가 상태를 반환한다. UTC=UT1과 극운동 0을 사용하는 근사는 별도 명시된 모드로만 허용하며 검증 모드의 조용한 대체값으로 사용하지 않는다. 윤초 경계의 전파 시간 계산은 별도 시험 대상으로 남긴다.

제주 가상 관측점은 기존 33.4996N,126.5312E와 타원체 높이 0m를 검토 후보로 둔다. 실제 시설이나 해발 높이라는 의미가 없으며 확정된 사용자 결정으로 기록하지 않는다.

## 공식 공개 위치 변환 fixture
출처: https://celestrak.org/publications/AIAA/2006-6753/AIAA-2006-6753-Rev2.pdf Appendix C, 인쇄 32쪽.
UTC 2004-04-06T07:51:28.386, UT1-UTC=-0.439961 s, TAI-UTC=32 s, xp=-0.140682 arcsec, yp=+0.333309 arcsec.
TEME 위치 km: [5094.18016210, 6127.64465950, 6380.34453270]
기대 ITRF 위치 km: [-1033.47938300, 7901.29527540, 6380.35659580]
위치 기준은 위 PDF 값만 사용한다. Astropy 시험 소스의 미세하게 다른 숫자와 혼합하지 않는다. PDF 파일의 로컬 확보와 해시 기록, 실제 계산 비교는 아직 남아 있다. 속도 fixture 검증에는 LOD 정의를 추가 확보한다.

## 고도각 및 구간 검증 계획
Astropy 공식 문서는 TEME에서 ITRS로 변환하고 관측점 위치를 빼 topocentric 위치를 만든 뒤 AltAz로 변환한다. pressure=0으로 기하학적 조건을 맞춘다. Astropy는 별도 시험 기준 후보이며 제품 필수 의존성 채택 결정이 아니다.
출처: https://docs.astropy.org/en/stable/coordinates/satellites.html
공개 ISS 예제의 고도각 숫자만 복사하지 않는다. 해당 예제의 site registry 및 IERS 입력이 모두 숫자로 고정되어 있지 않으므로 버전, 지점 좌표, EOP 파일/행/해시를 먼저 확보한다.

동일 입력의 기준 계산과 위치 10m, 고도각 0.01도, 가시 구간 시작/종료 1초 목표를 각각 비교한다. 관측점 바로 위/지평선/아래, 날짜 경계, 자료 범위 밖 및 잘못된 입력을 포함한다. 구간 탐색은 샘플 간 부호 변화와 경계 보정을 분리한다. 짧은 통과와 접점 누락 가능성을 시험하며 고정 간격 탐색만으로 모든 구간 발견을 보장하지 않는다. 경계 보정 종료 폭 0.1초는 검토용 내부 목표이며 외부 기준 대비 1초 정확도 검증을 대신하지 않는다.
