# 첫 단계 검증 목표 제안

2026-10-01. 정확도 및 사용성 수치는 사용자 동의로 첫 단계 목표 확정. 실제 측정/달성 증거는 없다.

## 정확도 구분과 추천
검증 의미 분리와 아래 수치 목표는 사용자 합의 완료. 기준: 같은 궤도 자료와 계산 조건의 기준 결과 일치 검증을 첫 단계 완료 기준으로 삼는다. 실제 ISS 위치 오차는 별도 관측/정밀 궤도 자료가 확보될 때 평가한다.

- SGP4 원시 위치 검증: 공개 Vallado 검증 입력/출력과 동일 시간, 좌표계(TEME), 중력 상수/계산 모드로 비교. 위치 벡터 차이 10m 이하를 첫 단계 수용 목표로 채택했다. 라이브러리 공식 시험의 더 엄격한 기준이 있으면 그대로 별도 실행한다.
- 지상국 고도각 검증: 동일 좌표계 변환/지구 모델/UTC/지점 높이로 별도 기준 계산과 비교, 절대 차이 0.01도 이하. 같은 함수 결과를 복제한 시험은 기준으로 사용하지 않는다.
- 가시 구간 경계: 같은 궤도와 10도 조건의 기준 교차 시각 대비 1초 이하. 임계값에 접하거나 매우 짧은 구간, 탐색 범위에서 잘린 경우 별도 시험. 정확히 경계에 있을 때 각도 허용 오차를 통신 여유로 사용하지 않는다.
- ISS 저장 입력: 자료 기준시각부터 24시간의 명시된 시험 구간 제안. 이 시간 범위는 입력 유효성 보장이나 실제 예측 오차 보장이 아니다.
- TLE와 OMM 입력은 원본의 반올림 차이 때문에 무조건 동일 결과로 간주하지 않는다. 의미상 동일한 요소로 만든 형식 변환 시험과 각 원본의 기준 결과 시험을 구분한다.

10m/0.01도/1초는 사용자와 합의한 본 프로젝트의 첫 단계 수용 목표다. 참고 문헌이 요구하는 표준값이라고 주장하지 않는다. 실제 검증 전 달성 여부 미확인.

## 합의된 사용성 목표
첫 단계 위성 1개/지점 1개, 1280x720 및 1920x1080, 실제 개발 PC의 브라우저/GPU/전원/버전 기록, 로컬 실행, 초기 자원 로딩 완료 후 측정한다.

| 조작 | 합의 목표 | 측정 |
|---|---|---|
| 창 이동/지구 회전 | 60fps 목표, 프레임 간격 95백분위 16.7ms 이하 | 30초 조작 3회, 표시 갱신 간격 기록 |
| 시간 변경 후 위치/수치 일치 | 지연 95백분위 100ms 이하 | 시각 변경 100회, 입력에서 일치 결과 표시까지 |
| 24시간 가시 구간 계산 | 95백분위 1초 이하 | 서로 다른 시작 시각 20회, 결과 표시까지 |
| 클릭/드래그 및 계산 중 다른 조작 | 입력 후 화면 피드백 95백분위 50ms 이하 | 구간 계산 중 창/시간 조작, 오래된 결과 덮어쓰기 0회 |

95백분위는 측정값의 95%가 목표 이내라는 뜻이다. 느린 나머지 사례와 최댓값도 보고한다. 첫 자원 로딩/네트워크 지연은 별도 보고하며 캐시된 조작 시험과 섞지 않는다. 측정 불가/목표 미달은 정상 완료로 기록하지 않는다. 실제 환경 측정 뒤 목표 변경 필요 시 이유를 함께 검토한다.

## 사용자 steering 반영
정확도 의미 분리는 사용자 동의로 확정했다. 사용자는 사용성 목표를 게임 기준으로 설정하도록 지시했다. 후속 사용자 동의로 60fps, 입력 피드백 50ms 및 표의 결과 완료 목표를 채택했다. 특정 게임 산업 표준값이라는 주장은 아니다. 120/144fps 등 고주사율 목표는 요구로 확정하지 않았다.

첫 단계는 60Hz 이상 디스플레이, 전경 활성 탭, 같은 개발 PC/브라우저/GPU/전원 조건에서 측정한다. requestAnimationFrame 호출 주기만으로 실제 지구 렌더링 프레임을 판정하지 않고 렌더 완료와 표시 갱신을 함께 계측한다. 95백분위 외 99백분위와 최댓값도 보고하여 순간 멈춤을 드러낸다. 계산 중 UI 피드백과 계산 결과 완료 시간을 구분한다. 결과가 늦어도 선택 시각/이전 결과/처리 상태를 정확히 표시한다.

위 사용성 수치는 후속 사용자 동의로 첫 단계 목표에 채택했다. 실제 측정/달성 검증은 미실행이다. 향후 위성 수 확대 시 같은 목표를 유지할 부하 조건은 별도 검토한다.
